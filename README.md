# ÁUA — премиальная ароматизация и фирменный аромат

Премиальный бренд сети: отели, бутики, рестораны, резиденции, сети. Визуальный язык — по референсу massage-self: бледно-голубой фон с чертёжной сеткой, гипсовые рендеры, интерактивные точки с выносками, переключатель «Точки / Список».

Сайт: https://t0niske.github.io/aua-maison/

## Структура (29 страниц)
- `/` — первый экран с макетом здания и кнопкой «Дегустация на объекте» → 10 пространств → фирменный аромат → метод → «Что мы проверяем перед запуском» → коллекция → дегустация → журнал → вопросы → три способа начать
- `/prostranstva/` + 10 пространств: зоны на макете, композиции, «Как внедряем», дегустация с выбранным типом; отель — «Фирменный аромат для отеля в Астане» с композициями по мотивам известных отелей
- `/signature/` — фирменный аромат: этапы, что получает клиент, «считаем под проект»
- `/aromabrending/`, `/aromamarketing/`, `/metod/`, `/kollekciya/` (метки: настроение, интенсивность, ноты, пространства)
- `/brif/` — бриф из пяти вопросов по одному на экран (`?type=otel` подставляет тип), уходит в WhatsApp
- `/dizajneram/`, `/zhurnal/` + 5 статей, `/kontakty/`
- `/usloviya/` — цены подписки; ссылка только из подвала и вопросов. На главной и в пространствах цен нет.
- `/kejsy/` появится с первым настоящим кейсом.

## Бизнес-данные — `src/config.js`
Свои контакты ÁUA, обещание скорости ответа, сроки шагов, состав «что получает клиент», счётчики Метрики и GA4. Пустые поля: контакты берутся из общих `lib/data.js`, блоки сроков не показываются.

Цели аналитики (уходят в `dataLayer`, в Метрику и GA4 — когда в конфиге появятся номера): `tasting_request` (форма дегустации), `brief_submit` (бриф), `deck_download` (презентация), `wa_click` (любая ссылка на WhatsApp), `brief_open`. В тексте WhatsApp всегда есть сайт и страница.

## Презентация PDF
`node tools/deck.js` собирает `src/assets/aua-presentation.pdf` из данных сайта (пространства, коллекция, этапы, контакты из конфига). После смены контактов — пересобрать презентацию, затем сайт.

## Картинки
Список и промпты — `IMAGES.md`. Положение точек — `x`/`y` в `src/content.js`.

## Как править и собирать
Тексты — `src/content.js` и `src/pages.js`, данные — `lib/data.js` (общие, мастер-копия в `sites/_engine`), стиль — `src/assets/css/style.css`.
```
node build.js
```
