# ÁUA — премиальная ароматизация пространств

Имиджевый сайт для отелей, резиденций, бутиков и офисов Астаны. Тёмная журнальная подача, огромная широкая типографика и 3D-модель диффузора Nova 1000 с дымкой аромата (Three.js).

**Сайт:** https://t0niske.github.io/aua-maison/

## Что на странице
- Заставка, первый экран с 3D-диффузором (реагирует на мышь и прокрутку)
- Манифест и три факта об обонянии
- «Метод» — сцена из 4 шагов, закреплённая при прокрутке
- Коллекция из 32 ароматов с фильтром по категориям
- Пространства (6 отраслей) с рекомендованными ароматами
- Nova 300 / Nova 1000: характеристики и подписка на 1, 3, 6 месяцев
- OdorOut™, цифры компании, FAQ, форма заявки в WhatsApp

## Как менять данные
Цены, ароматы, отрасли, контакты и FAQ — в `js/data.js`. Цены взяты из прайсов Nova 300 / Nova 1000.

## Структура
`index.html` · `css/style.css` · `js/data.js` (данные) · `js/scene.js` (3D) · `js/main.js` (интерактив). Сборка не нужна — это статический сайт.
